Daniel Meppiel

Director, Agentic SDLC GTM at Microsoft. Author of The Agentic SDLC Handbook.

I believe we are in the early chapters of a fundamental shift in how software gets built: not only faster code generation, but a rethinking of how engineering organizations operate when every developer works alongside AI agents.

I have spent 14+ years on this trajectory: distributed systems at CERN, developer tools at GitHub and Sonar, and founding an AI startup as CTO (WeGaw, backed by the European Space Agency). Today I am a Director at Microsoft, leading GTM for the Agentic SDLC.

I created APM, Microsoft’s open-source Agent Package Manager, now supported by GitHub’s Dependabot and by Renovate. I designed the PROSE specification for writing agent instructions that hold up. I wrote The Agentic SDLC Handbook, everything I have learned about making AI-native development work at scale. And I build APMX, an independent, experimental runner for verifiable agentic software factories.

What you will find in the handbook

  1. Why AI-native development is more than adopting a coding agent. Copilot, Claude or Cursor change how one developer works. What engineering organizations need to change is bigger.
  2. The governance gap. How productivity gains disappear when AI-generated code reaches review, compliance and architecture standards.
  3. Agent onboarding. Patterns that treat coding agents like new hires, with context, standards and guardrails built in.
  4. The PROSE specification. A framework for writing agent instructions that are precise, composable and version-controlled.
  5. A two-command implementation pattern. apm install, then apm compile.
  6. The full method. From one developer’s setup to agent governance across an enterprise.

Projects

  • APM. Microsoft’s open-source Agent Package Manager: declares the skills, prompts and plugins your coding agents use as dependencies, pins them, and governs them with one org-wide policy.
  • APMX. An independent, experimental open-source runner for agentic software factories: runs Agent Contracts on your coding agent, writes the receipt and provides the gate at merge.
  • Genesis. An architectural layer for designing multi-agent, multi-skill systems with named patterns and contracts, before you write them. It applies the handbook’s architecture patterns to skill design; Appendix B walks through an example.
  • Agent Contracts & Receipts. Format draft 0.1, open for comment: read the spec, join the discussions.
